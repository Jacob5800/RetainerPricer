# Retainer Pricer

Dalamud API 15 plugin for pricing items in the retainer sale window.

## Use

1. Open the plugin with `/retainerpricer` from the main menu or while viewing a retainer's selling list.
2. Automatic new-item pricing and both batch actions use Universalis. A price is only suggested when there is a current competing listing of the same quality and a sale from the previous 20 days.
3. Open a retainer's sale list and click **Start listing items**. It processes all eligible carried inventory automatically: skips untradeable, nonmarketable, excluded, or inactive items; checks Universalis; sets one gil below the lowest matching listing; and confirms each new sale. Each sale is capped at 99 items; larger stacks continue in follow-up listings. Items configured on the **Batch selling** tab are split into smaller listings; other items stay as full stacks up to that cap. Items with no current price or no sale during the previous 20 days are skipped with an explanation. It stops when eligible inventory is done, the retainer's 20 slots are full, or you press **Stop**. If it cannot verify that a sale reached the retainer list, it stops before trying another item.
4. In **Batch selling**, use **Add current inventory** to add eligible carried items in one step, or add items individually. Set a maximum quantity per listing and an optional maximum total for that item in a **Start batch selling only** run. No sale exceeds 99 items; larger quantities continue in another listing if space remains. For example, a batch size of 5 and total limit of 20 lists at most 20 items in four listings; 0 means no total limit. **Start listing items** still processes all eligible inventory, using the per-listing size. **Start batch selling only** processes only configured items; all other carried inventory is ignored. Exclusions take priority, and listing stops at the normal 20-slot limit.
5. To check a price without listing, use **Price lookup** and retrieve from a captured inventory or retainer-list row. When **Automatically price and confirm new listings** is enabled, opening an eligible new sale window checks Universalis, submits the listed price, and verifies it in the retainer list. Use **Start listing items** to process all eligible carried inventory in one run.
6. To automatically reprice all retainers, click **Auto update** from the retainer picker to go top-to-bottom, or open any retainer's selling list to process that retainer first. It then visits each other available retainer once. Inactive retainers are skipped. It uses your price scope and exclusions, verifies every changed listing, shows the current retainer and item, and stops if the character, world, or selected retainer changes unexpectedly. **Stop** prevents further submissions; already submitted changes remain applied. This currently requires the game UI language to show the standard English retainer menu labels.
7. To reprice only the active retainer, click **Update existing listings**. It checks each eligible listing against Universalis, sets the price one gil below the lowest matching listing, submits the update, and verifies it before moving to the next item. No review/apply step is needed. Rows show whether a price was applied or skipped for missing recent history or competition; use **Exclude** to add an item to the persistent exception list. Changing character, world, or active retainer stops an update.

Prices compare HQ and NQ separately, exclude all of your retainers, and target one gil below the lowest usable competing listing. Inventory snapshots read the four carried inventory bags; untradeable items and items without a marketboard search category are skipped automatically. The optional maximum-age filter is off by default. Use the **Exceptions** tab to grab carried inventory, filter item names, select an item from the dropdown, and add or remove persistent exclusions. The picker hides items already excluded; use **Add current inventory** to exclude all marketable items in your carried inventory at once. Excluded items remain visible in the list with a **Remove** button, while manual price lookups remain available. On-screen price checks and automatic batches use Universalis. Automated runs stop if the character disconnects, begins loading or logging out, changes character or world, or the active retainer/item/menu transition cannot be verified; an item without a usable price is skipped. If **Start batch selling only** is clicked before adding any items to the **Batch selling** tab, the plugin shows “Batch selling list is empty.”

Successful Universalis responses are cached in memory for 5 minutes by default, keyed by market scope and item. Change the cache window or turn it off in **Settings**; the optional price-upload age filter remains independent. **Use lowest price in the Data Center** is an optional setting, off by default; when enabled, Universalis pricing uses all listings on the home world's Data Center. **Use lowest price in region** is a separate optional setting, also off by default; it checks every Data Center in the home world's region and includes Oceania (Materia), and applies to automatic pricing and manual lookups. The Data Center and region options are mutually exclusive. The **On-screen price check source** selector offers Universalis. Per-item batch sizes affect new listings only; the batch-only total cap limits how much of that item is listed during one batch-only run. Existing listings are repriced without changing their quantities. The plugin version appears at the bottom-left of the menu.

Universalis requests are on demand and are limited to the selected item and the configured market scope. Items are left unchanged when Universalis has no matching current listing or no sale from the previous 20 days. The plugin does not upload player or market data.

## Install

In Dalamud Settings → Experimental → Custom Plugin Repositories, add `https://raw.githubusercontent.com/Jacob5800/RetainerPricer/main/repo.json` for installer updates.
